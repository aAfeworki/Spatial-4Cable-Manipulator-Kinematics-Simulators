# Spatial-4Cable-Manipulator-Kinematics-Simulators
Interactive Python-based simulators for the Spatial 4-Cable Manipulator, featuring forward kinematics with slider control, forward kinematics driven by inverse kinematics solutions, and an inverse kinematics simulator.



This repository provides interactive simulators for the Spatial 4-Cable Manipulator, implemented in Python using `matplotlib`.  
It demonstrates both forward and inverse kinematics, enabling visualization and understanding of 3D cable-driven parallel manipulators.  



🚀 Features
- Forward Kinematics (Slider-Controlled)
  Adjust cable lengths with sliders to control the position of the end-effector in 3D space.  

![image alt](https://github.com/aAfeworki/Spatial-4Cable-Manipulator-Kinematics-Simulators/blob/main/FK_Simulator_for_4_Cable_Spatial_manipulator_with_Slider.png?raw=true)

- Forward Kinematics (IK-Driven)
  Drive the manipulator using cable lengths generated by the inverse kinematics solver.  

![image alt](https://github.com/aAfeworki/Spatial-4Cable-Manipulator-Kinematics-Simulators/blob/main/FK_Simulator_for_4_Cable_Spatial_Industrial_Robot.png?raw=true)

- Inverse Kinematics Simulator
 Enter the equation of a curve on the User Interface to generate joint angles that position the manipulator’s end-effector.

![image alt](https://github.com/aAfeworki/Spatial-4Cable-Manipulator-Kinematics-Simulators/blob/main/IK_Generator_for_4_Cable_Spatial_manipulator_with_Simulator.png?raw=true)

![image alt](https://github.com/aAfeworki/Spatial-4Cable-Manipulator-Kinematics-Simulators/blob/main/IK_Generator_for_4_Cable_Spatial_manipulator_with_Simulator%20user%20interface.png?raw=true)
